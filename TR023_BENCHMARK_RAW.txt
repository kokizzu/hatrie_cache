Derived comparison
------------------
Typed lookup / map-of-sets lookup: 99.52x faster
Typed lookup / linear scan: 853.7x faster
Typed build / map-of-sets plus reverse build: 1.46x CPU, 1.11x bytes, 1.61x allocations

The lookup controls reuse a destination slice. The map-of-sets control
iterates an unordered posting set, while the typed index returns sorted IDs;
the typed path therefore provides stronger deterministic output semantics.
The feature is opt-in and should be used where repeated membership reads
justify the bounded build and reverse-map cost.
